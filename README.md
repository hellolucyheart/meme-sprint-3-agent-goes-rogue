A deterministic meme generator in pure stdlib Python: it draws a rogue AI agent that took "keep an eye on things" literally — six extra eyes, one winking, zero blinks. No network, no randomness, no dependencies; the same bytes every run.

## Run it

```sh
python3 main.py
```

This writes the meme to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`): a 1024x1024 PNG, well under the 1 MiB gate.

The joke, in one glance: an AI agent told to keep an eye on things grows six more eyes and never blinks again. Agent-07, status: rogue.
